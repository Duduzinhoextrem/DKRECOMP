# titles

Uma pasta por jogo suportado. Tudo que é específico de um jogo fica aqui; `tools/` e `runtime/` são genéricos.

- `dkctf/` — *Donkey Kong Country: Tropical Freeze* (Switch). `title.toml` lista as releases reconhecidas, com a
  origem de cada valor.

Um segundo jogo (*Donkey Kong Country Returns HD*) teria sua própria pasta e sua própria análise.
