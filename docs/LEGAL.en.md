# What may and may not go on GitHub

Português: [LEGAL.md](LEGAL.md)

These are the project's technical rules. They are not legal advice: the law on backups, reverse engineering and
interoperability differs between countries.

## What DKRecomp is

A tool that converts, on the user's own machine, files the user took from their own copy of the game. The repository
holds only the project's code and documentation, plus third-party code under compatible licenses, listed in
`THIRD_PARTY_NOTICES.md`. The converted game never leaves the computer of the person who converted it.

## Allowed on GitHub

| What | Examples | Note |
|---|---|---|
| DKRecomp's own code and documentation | `tools/`, `runtime/`, `docs/`, `tests/` | |
| Tests built on synthetic data | shaders in `tests/native/shaders/`, programs in `tests/diff/` | Written by the project, with no bytes from the game |
| Third-party code under a permissive license | ASTC decoder from LAS Recomp, translator from TotK Recomp, deko3d texture layout | MIT, BSD, ISC, zlib or Apache-2.0 only, with the license text and a line in `THIRD_PARTY_NOTICES.md` |
| Release identifiers | `titles/dkctf/title.toml`: SHA-256 hashes, title and build IDs, sizes | They recognize a release; they cannot rebuild the game |
| Facts about the binary, written in our own words | addresses, offsets, IPC command IDs, structure layouts, SDK function names | Needed for interoperability. Never copy game code or data along with them |
| Public NVN API names | `runtime/gfx/third_party/nvn_procs.inc` | MIT-licensed list from TotK Recomp |
| Scripts that download open-source tools from their official sources | SDL3, Vulkan-Headers | The downloads stay in `toolchain/`, outside Git |

## Never allowed on GitHub

| What | Examples |
|---|---|
| Game files | NSP, XCI, NCA, NSO, NPDM, NACP, tickets, certificates, ExeFS and RomFS contents |
| Anything derived from the game | generated C (`generated/`), `dkctf.exe`, module `.img` images, `romfs.bin`, translated shaders (`.maxwell`, `.spv`, `.dkrspv`), `pipelines.bin`, `.bmp` captures, logs and reports with extracted content (`reports/`), the `DKRecomp-Portatil/` folder |
| Keys and console data | `prod.keys`, `title.keys`, firmware, console-unique data |
| Bundled decryption tools | `nstool` is always the user's own (a project decision, confirmed on 2026-11-03) |
| Personal saves and settings | `user_files/saves/`, `config.local.toml` |
| GPL or unlicensed code | yuzu, older GPL versions of Ryujinx, the Unicorn core. Study them or use them as test tools; never copy them |
| Game art, logos and music | icons, screens or soundtrack extracted from the game |

Repositories that published keys, key-dumping tools or game files have been taken down from GitHub after removal
requests. DKRecomp avoids both: it stores no keys or game content and implements no decryption.

## Rules for the code

1. DKRecomp never reads, stores or prints keys. The ticket reader (`tools/dkrecomp/formats/ticket.py`) returns
   identifiers only and never touches the title key block. The launcher asks where the user's `nstool` and
   `prod.keys` are and passes those paths to `nstool`; DKRecomp itself never opens the key file.
2. DKRecomp decrypts nothing and bypasses no protection. It reads only plaintext data (the PFS0 header, public ticket
   fields, `.cnmt.xml`) and files the user has already extracted.
3. No tool downloads games, updates, keys or firmware.
4. The converted game is for personal use. Generated C starts with the notice
   `GENERATED BY DKRecomp - do not edit. Derived from the input binary: keep out of version control.` The executable
   and the portable package must not be shared either.
5. *Donkey Kong Country*, *Tropical Freeze* and *Nintendo Switch* are trademarks of Nintendo. Keep official logos and
   art out of the repository, and keep the notice that the project has no affiliation with Nintendo or Retro Studios.

## Before every push

```bash
.venv/Scripts/python tools/check_content.py
git status --short
```

`check_content.py` checks every tracked file and fails on a forbidden extension or folder, a binary file that is not
on its allow list, or an oversized file. `.gitignore` already blocks `game original meu/`, `user_files/`,
`SwitchExtract/`, `build/`, `generated/`, `reports/`, `refs/` and `toolchain/`.

One thing is not a legal issue but becomes public with the first push: each commit shows its author's name and email
on GitHub. To hide the email, use the `noreply` address GitHub offers in its email settings. Existing commits keep
the old address unless the history is rewritten before the first push.
